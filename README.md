
# Chatverse

Chatverse is a modern, responsive real-time chat application built using the PERN stack (PostgreSQL, Express, React, Node.js) with Tailwind CSS for styling. It provides seamless communication between users with instant messaging and a sleek user interface.

# Features

* Real-time messaging: Instant communication between users.

* Responsive design: Tailwind CSS ensures the app looks great on all devices.
* Modern tech stack: Powered by PostgreSQL, Express, React, and Node.js.
* Scalable backend: Designed for efficiency and scalability with RESTful APIs.
* User-friendly interface: Clean and intuitive UI for easy navigation and messaging.



# Tech Stack


PERN Stack + Socket io + Tailwind
